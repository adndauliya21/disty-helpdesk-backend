# latihan/ : latihan PHP murni (Modul 2)

Kode **tidak dipindah**. Folder aslinya `latihan/php/` (sudah punya `README.md` sendiri).

Back-end aduan dalam PHP murni, tanpa framework dan tanpa Composer.

| Perlu apa | Buka |
|---|---|
| Penjelasan konsep tiap berkas | `latihan/php/README.md` |
| Titik masuk | `latihan/php/public/index.php` |
| Kelas | `latihan/php/src/` (`Request`, `Response`, `Aplikasi`, `Validator`, `TokoAduan`, `StatusAduan`, `ApiException`) |
| Uji | `php uji.php` dari dalam `latihan/php/` |

Silabus: Modul 2, Bahasa Pemrograman Back-End.

## Aturan
- `.dockerignore` mengecualikan `latihan`, jadi folder ini tidak ikut ke image Docker. Jangan dipindah tanpa menyesuaikan berkas itu.
