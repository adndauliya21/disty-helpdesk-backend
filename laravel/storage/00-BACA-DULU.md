# storage/ : berkas yang dibuat aplikasi saat berjalan

| Folder | Isi |
|---|---|
| `logs/` | Catatan galat (`laravel.log`). Dibuat otomatis |
| `framework/` | Cache, sesi, dan tampilan sementara. Dibuat otomatis |
| `app/` | Penyimpanan berkas Laravel. `foto-profil/` saat ini kosong |

Isi folder ini boleh dihapus kapan saja, kecuali berkas `.gitignore` di dalamnya.
Foto unggahan pengguna tidak di sini. Lokasinya `public/uploads/`.
